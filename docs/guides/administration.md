# 管理员指南

[返回首页](../../README.md) · [English](administration.en.md) · [配置指南](configuration.md) · [部署与维护](deployment.md)

## 创建管理员

在项目根目录运行：

```bash
pnpm admin:setup-token
```

打开 `/transformer/setup`，填写初始化码、管理员账号和至少 12 位的密码，并确认初始运营设置。初始化码有效期为 15 分钟，只能使用一次；未持有码的访客无法创建管理员。

本地开发入口为 `http://localhost:5173/transformer/setup`。服务器运行管理命令时必须使用服务相同的环境文件和数据路径，参见[部署初始化](deployment.md#初始化管理员)。

## 登录和密码恢复

通过 `/transformer/login` 登录，之后访问 `/transformer/admin/settings`。工作区侧边栏同样提供入口。管理员会话最长 7 天，服务重启、退出登录或修改密码后需要重新登录。

忘记密码时，在项目根目录、使用服务相同的运行环境执行：

```bash
pnpm admin:reset-password
```

在登录页选择“恢复密码”，输入 15 分钟内有效的一次性恢复码和新密码。原账号名保留。如果忘记账号名，服务器管理员可以从运行数据的管理员记录中查看；不要将运行文件提供给他人。

## 运营设置

| 设置 | 新安装默认值 | 行为 |
| --- | --- | --- |
| 访问隔离 | 开启 | 按浏览器 Cookie 隔离任务，公开示例除外 |
| 每日额度 | 开启，5 次 | 按浏览器统计每日上传；管理员不限额、不计入普通用量 |
| 额度时区 | `Asia/Shanghai` | 按该时区划分日期，修改后使用新的日期边界 |
| SVG 上传大小 | 50 MB | 可设置 1–50 MB，管理员同样受限制 |
| 单任务预计耗时 | 20 分钟 | 只用于排队估算，不改变实际并发 |
| 用户提交公开示例 | 允许 | 关闭后禁止新提交，已有示例保留 |

保存后新请求立即使用新策略，已接受的转换不受影响。其他页面会在重新获得焦点或定时刷新时更新。多人同时编辑发生版本冲突时，重新加载当前设置，再确认需要修改的值并保存。

### 访问隔离

关闭访问隔离后，所有访客都能查看、预览和下载全部已有任务。他人的任务仍只读；修改和删除权限仍由任务归属、管理员身份及示例规则决定。

重新开启隔离不会改变原有任务归属，会终止失去权限的活动事件流和下载流。已经下载的文件无法收回。

Cookie 是匿名浏览器身份，不是正式用户账号。清除 Cookie 或更换浏览器会失去原归属，同时获得新的额度身份；每日额度不能替代入口限流。

### 每日额度

关闭额度后仍记录用量，重新开启不会清空当天记录。修改时区会改变额度重置的日期边界，已接受的任务继续运行。

### 公开示例

管理员可在“公开示例”页面设置或取消任意任务的示例状态。关闭“允许用户提交公开示例”只影响后续用户提交，不会撤销已有示例。普通用户不能删除示例，管理员可以删除。

## 排队与并发

在“排队与并发”中设置全站最多同时执行的 session 数，范围为 1–32，并使用页面底部按钮保存。

- 调高上限后，Core 立即补入排队任务。
- 调低上限后，现有任务自然完成，不会被中断。
- 单个 session 内的模块并发不受影响。
- 排队等待估算读取 Core 的实际执行上限。

该功能要求 Core 支持 `GET/PUT /api/queue/settings`；旧 Core 会显示升级提示，无法保存时不会显示保存成功。Core 将实际执行上限保存在工作目录的 `queue-settings.json`；首次尚未保存时使用 `MAX_CONCURRENT_AGENTS`，之后重启优先使用已保存值。

此文件属于运行数据，备份时与整个 Core 工作目录一并保留，不应放入 Git 或代码快照。Core 的执行 API 只允许可信网关访问；网关要求管理员登录后才能修改并发设置。

## 从旧管理员密钥迁移

已有 ToC 管理员密钥时，可在登录页选择“使用原管理员密钥迁移”，或使用原有 `#adminKey=...` 入口，然后创建账号。成功后旧密钥和旧会话停止生效。新安装直接使用一次性初始化码，无需设置旧密钥。

旧运营环境配置只在缺少在线设置文件时导入，后续以网页设置为准。运行数据和历史任务的迁移规则见[部署与维护](deployment.md#备份与迁移)。
